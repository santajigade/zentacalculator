    Calculators built for the plant floor

    These tools cover the everyday sums of process instrumentation: converting transmitter signals, checking loop power budgets, sizing primary flow elements and turning level into volume. They use the same equations found in ISO 5167, IEC 60751 and standard fluid-mechanics references, with units you can switch between metric and imperial.

    Solve for any value

    Unlike fixed-direction calculators, every field can be an input or an output. Enter a flow and solve for differential pressure, or enter a target process value and get the mA signal. Each result shows the formula used so you can check the working.

    Flow and level measurement

    For differential pressure flow, size the primary element with the orifice flow or Venturi calculator, then set the transmitter range with the DP flow square root calculator. Pulse output meters need the K-factor calculator, and gas meters reading at line conditions need gas flow correction to standard conditions. For level, set a DP transmitter range with the DP level range calculator, then convert level into volume for a vertical, horizontal or spherical tank.

    Control, calibration and safety

    Check a loop before commissioning with the loop resistance and 4-20 mA scaling calculators, and verify instruments with the calibration error and five-point calibration tools. Tune controllers with Ziegler-Nichols or lambda tuning from a FOPDT step test. For functional safety, the PFDavg and safe failure fraction calculators follow IEC 61508 and IEC 61511.

    Frequently asked questions

    Are these engineering calculators free?

    Yes. All calculators are free, need no sign-up and work on mobile.

    Which standards do the flow calculators follow?

    Orifice and Venturi calculators use the ISO 5167 flow equation with a user-entered discharge coefficient; the Pt100 calculator uses the IEC 60751 Callendar–Van Dusen equation.

    Can I embed a calculator on my website?

    Yes. Every calculator has an Embed button that gives you a copy-paste code snippet.

    Who builds these engineering calculators?

    They are written and checked by an electronics and instrumentation engineer with hands-on experience of process instruments, and every formula is shown on the page so you can verify it.
