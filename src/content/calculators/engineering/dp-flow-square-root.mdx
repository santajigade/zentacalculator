## How to use the DP flow square root calculator

Enter the transmitter's **DP range** (DP at maximum flow) and the **maximum flow**. Then type the **measured DP** — or a percentage — to get the actual flow. You can also work backwards: type a flow to see the DP it should produce.

For more background, read [DP Flow Transmitter 5-Point Calibration](https://www.instrumentationblog.in/dp-flow-transmitter-calibration-5-point/).

## DP flow square root formula

<p class="formula">Flow % = √(DP %)   Q = Q<sub>max</sub> × √(ΔP ÷ ΔP<sub>max</sub>)</p>

## Worked example

Range 0–250 mbar = 0–100 m³/h. Measured DP = 62.5 mbar.

- DP % = 62.5 ÷ 250 = 25%
- Flow % = √0.25 = 50%
- Flow = **50 m³/h**

## DP vs flow table

| DP % | Flow % |
|---|---|
| 1% | 10% |
| 4% | 20% |
| 9% | 30% |
| 25% | 50% |
| 49% | 70% |
| 81% | 90% |
| 100% | 100% |

At 10% flow the transmitter sees only 1% of its range, which is why turndown is limited.

## Low-flow cut-off

Because flow is the square root of DP, small DP errors near zero become large flow errors. A 0.1% DP zero error appears as about 3.2% of flow. Most transmitters and DCS blocks apply a **low-flow cut-off**, often 5–10% of flow, below which the reading is forced to zero.

## Rangeability (turndown)

DP flow meters have limited turndown, typically 3:1 to 4:1, because DP falls with the square of flow:

| Flow (% of max) | DP (% of max) |
|---|---|
| 100% | 100% |
| 50% | 25% |
| 25% | 6.25% |
| 10% | 1% |

At 10% flow the transmitter is measuring only 1% of its range. For wider turndown, use two transmitters with different ranges, or a different meter type.

## Where to take the square root

The square root can be done in the transmitter (output linear with flow) or in the DCS (transmitter output linear with DP). Do it in **one place only**. Taking it twice is a common commissioning error.

## Primary elements that use this

- Orifice plates — see the [orifice flow calculator](/engineering/orifice-flow/)
- Venturi tubes and flow nozzles
- Averaging pitot tubes
- Wedge and V-cone meters

## With a 4–20 mA signal

If the transmitter output is linear with DP, mA = 4 + 16 × DP%. For 50% flow (25% DP) that is **8 mA**, not 12 mA. If the transmitter extracts the square root itself, 50% flow reads 12 mA. Use the [4–20 mA calculator](/engineering/4-20ma-scaling/) for the conversion.

## Second example: reading the output current

With the same 0 to 250 mbar, 0 to 100 m³/h range, suppose the transmitter sees **160 mbar**. DP is 64% of range, so flow is √0.64 = **80%**, or 80 m³/h. A transmitter set to linear DP output sends 14.24 mA, while one set to square root output sends 16.80 mA. If the DCS then applies a second square root to the 16.80 mA signal, it displays 89.4% flow, 9.4 m³/h too high, which is the classic double extraction error.

## How a small DP error grows at low flow

Take a zero error of only 0.1% of span (0.25 mbar). Its effect on the flow reading depends on where in the range you are:

| Flow | DP at that flow | Flow error | Error as % of reading |
|---|---|---|---|
| 10% | 2.50 mbar | 0.488 m³/h | 4.88% |
| 20% | 10.00 mbar | 0.248 m³/h | 1.24% |
| 30% | 22.50 mbar | 0.166 m³/h | 0.55% |
| 50% | 62.50 mbar | 0.100 m³/h | 0.20% |
| 70% | 122.50 mbar | 0.071 m³/h | 0.10% |
| 100% | 250.00 mbar | 0.050 m³/h | 0.05% |

The same 0.25 mbar that is invisible at full flow becomes a 4.88% error at 10% flow. This is the reason for low flow cutoff and for keeping the normal operating point above about 30% of the meter range.

## Checking the loop in the field

- Isolate the transmitter on its 3 or 5 valve manifold, open the equalising valve and confirm the output reads zero DP, then zero flow in the DCS.
- Inject DP with a hand pump and calibrator at 0, 25, 50, 75 and 100% of DP and record both the mA and the displayed flow. The displayed flow should be 0, 50, 70.7, 86.6 and 100%.
- Confirm the DP range matches the orifice sizing sheet. If the plate was sized for 250 mbar at 100 m³/h, a transmitter ranged at 0 to 200 mbar would saturate before maximum flow.
- On liquid service vent gas from the impulse lines; on gas service drain liquid, since a trapped leg adds a fixed DP offset.

## Common mistakes

- **Square rooting in two places.** Decide whether the transmitter or the DCS extracts the root, and document it on the loop sheet.
- **Swapping the HP and LP lines.** A reversed DP reads negative or clamps at zero, so the meter shows no flow while the line is running.
- **Ignoring a change in fluid density.** Volumetric flow follows √(ΔP ÷ ρ). A fluid 5% denser than the design value makes the reading about 2.5% high.
- **Setting the cutoff too high.** A 10% flow cutoff hides real low flow during start up; set it just above the noise level.
- **Ranging the transmitter on site without the orifice calculation.** The DP at maximum flow comes from the plate bore and fluid data, not from a round number.
