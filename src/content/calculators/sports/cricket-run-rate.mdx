## How to use the cricket run rate calculator

Enter the **runs scored** and **balls faced** (or overs × 6). The overs and run rate are calculated.

## Cricket run rate formula

<p class="formula">Run rate = runs ÷ (balls ÷ 6)</p>

## Example

168 runs in 20 overs (120 balls) → run rate **8.40**.

## Overs and balls

| Overs notation | Balls | Decimal overs |
|---|---|---|
| 5.0 | 30 | 5.000 |
| 5.1 | 31 | 5.167 |
| 5.3 | 33 | 5.500 |
| 10.4 | 64 | 10.667 |
| 19.5 | 119 | 19.833 |
| 49.2 | 296 | 49.333 |

Never use “10.4 overs” as 10.4 in calculations — it means 10 overs and 4 balls, which is 10.667 overs.

## Projected score

<p class="formula">Projected total = current runs + run rate × overs remaining</p>

At 85 for 2 after 10 overs in a T20 (run rate 8.5), the projected total is 85 + 8.5 × 10 = **170**.

## Typical run rates

| Format | Typical scoring rate |
|---|---|
| Test | 3–3.5 runs per over |
| ODI | 5.5–6.5 runs per over |
| T20 | 8–9 runs per over |

## Required run rate

When chasing, compare the current run rate with the required rate — see the [required run rate calculator](/sports/required-run-rate/).

## Overs notation

In cricket, "15.3 overs" means 15 overs and 3 balls — not 15.3 as a decimal. It equals 93 balls or 15.5 decimal overs.
