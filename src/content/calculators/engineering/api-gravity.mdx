## How to use the API gravity calculator

Enter the **API gravity** to get specific gravity and density at 60 °F, or enter **specific gravity** or **density** and press × on API gravity to convert the other way.

## API gravity formula

<p class="formula">°API = 141.5 ÷ SG − 131.5 &nbsp;·&nbsp; SG = 141.5 ÷ (°API + 131.5)</p>

Density uses water at 60 °F (999.016 kg/m³).

## Temperature correction

API gravity is defined at 60 °F (15.6 °C). Hydrometer readings at other temperatures are corrected to 60 °F with the API MPMS Chapter 11.1 tables before use.

## Worked example

A diesel sample reads **35 °API**:

- SG = 141.5 ÷ (35 + 131.5) = 141.5 ÷ 166.5 = **0.8498**
- Density = 0.8498 × 999.016 = **849.0 kg/m³** at 60 °F
- Mass of one barrel (158.987 L) = 0.849 × 158.987 = **135.0 kg**

Going the other way, a crude with SG 0.876 is 141.5 ÷ 0.876 − 131.5 = **30.0 °API**, a medium crude.

## Why the scale looks inverted

The API scale grew out of the older Baumé hydrometer scale, and it was built so that light oils give large, easy-to-read numbers. Because SG sits in the denominator, API gravity rises as oil gets lighter, and equal steps in °API are not equal steps in density. A change from 10 to 20 °API is a bigger density change than one from 40 to 50 °API.

## How API gravity is measured

- **Glass hydrometer** (ASTM D1298 or D287): the classic method. Read the hydrometer and the sample temperature, then correct to 60 °F.
- **Digital density meter** (ASTM D4052): an oscillating U-tube gives density to 4 or 5 decimals in a few minutes.
- **Online measurement:** Coriolis flow meters and inline density meters measure density continuously, so custody transfer systems can report API gravity in real time.

## Using API gravity in measurement

Tank gauging and many flow meters measure **volume**, but oil is bought and sold by standard volume or mass. The density from API gravity converts one into the other (see the [mass flow rate calculator](/engineering/mass-flow-rate/)), and the API volume correction tables use it to correct the volume to 60 °F. For level work, the same density sets the range of a differential pressure transmitter.

## Common mistakes

- **Using API gravity measured at a different temperature.** Always correct the reading to 60 °F first.
- **Averaging API values for blends.** Blend densities or specific gravities by volume, then convert the result back to API.
- **Using 1,000 kg/m³ for water.** The standard uses water at 60 °F, which is 999.016 kg/m³.
- **Confusing 60 °F with 15 °C.** Many countries report density at 15 °C. The two reference temperatures differ slightly, so the numbers are close but not identical.
