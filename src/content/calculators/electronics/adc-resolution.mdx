## How to use the ADC resolution calculator

Enter the ADC's **resolution in bits**, the **full-scale reference voltage** and an **input voltage**. You get the number of levels, the step size, the digital code and the theoretical signal-to-noise ratio.

For more background, read [PLC Analog Scaling from Raw Counts](https://www.instrumentationblog.in/plc-analog-scaling-raw-count/) and [ADC Working Principle](https://www.instrumentationblog.in/adc-working-principle-explained/).

## ADC resolution formulas

<p class="formula">LSB = V<sub>ref</sub> ÷ 2ⁿ &nbsp;·&nbsp; Code = ⌊V<sub>in</sub> ÷ LSB⌋ &nbsp;·&nbsp; SNR<sub>ideal</sub> = 6.02n + 1.76 dB</p>

## Getting the best from an ADC

- Use a stable, low-noise reference — its error appears directly in every reading.
- Filter the input below half the sample rate to prevent aliasing — see the [RC filter calculator](/electronics/rc-filter/).
- Average or oversample: averaging 4ⁿ samples adds about n bits of resolution when noise is present.

## Worked example with the default values

A 12-bit ADC with a 3.3 V reference reading 1.65 V:

1. Levels = 2¹² = **4,096**
2. LSB = 3.3 ÷ 4,096 = **0.8057 mV**
3. Code = ⌊1.65 ÷ 0.8057 mV⌋ = **2,048**
4. Ideal SNR = 6.02 × 12 + 1.76 = **74.00 dB**

Code 2,048 covers every input from 1.65000 V up to 1.65081 V, so the reading carries an uncertainty of one LSB, or ±0.403 mV about the centre of the step. Treated as noise, that quantisation error has an RMS value of LSB ÷ √12 = 0.2326 mV, which is where the 6.02n + 1.76 dB figure comes from.

## What one count means for a sensor

A temperature sensor with a 10 mV/°C output on this converter resolves 0.8057 mV ÷ 10 mV = **0.0806 °C per count** and spans 0 to 330 °C at full scale. If the process only runs 0 to 100 °C, two thirds of the codes go unused; an amplifier gain of about 3 restores the resolution.

## Oversampling for extra bits

| Extra bits | Samples averaged | Effective bits | Effective LSB at 3.3 V |
|---|---|---|---|
| 0 | 1 | 12 | 0.8057 mV |
| 1 | 4 | 13 | 0.4028 mV |
| 2 | 16 | 14 | 0.2014 mV |
| 3 | 64 | 15 | 0.1007 mV |
| 4 | 256 | 16 | 0.0504 mV |

This only works when at least about one LSB of random noise is present; a perfectly quiet input returns the same code every time and averaging gains nothing.

## Common mistakes

- **Dividing by 2ⁿ − 1.** Some datasheets define full scale at code 4,095, giving 0.8059 mV per count; check which convention the part uses.
- **Trusting the reference.** A 1% reference error shifts full scale by 33 mV, about 41 counts, far more than the resolution.
- **Confusing resolution with accuracy.** Offset, gain and linearity errors are specified separately and usually exceed 1 LSB.
- **Feeding a SAR ADC from a high source impedance.** The sampling capacitor cannot charge within the acquisition time, so readings sag; buffer the input or lengthen the sample time.
- **Expecting all bits to be useful.** A measured SNR of 66 dB means ENOB = (66 − 1.76) ÷ 6.02 = 10.67 bits, not 12.
