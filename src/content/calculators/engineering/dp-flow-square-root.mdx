## How to use the DP flow square root calculator

Enter the transmitter's **DP range** (DP at maximum flow) and the **maximum flow**. Then type the **measured DP** — or a percentage — to get the actual flow. You can also work backwards: type a flow to see the DP it should produce.

For more background, read [DP Flow Transmitter 5-Point Calibration](https://www.instrumentationblog.in/dp-flow-transmitter-calibration-5-point/).

## DP flow square root formula

<p class="formula">Flow % = √(DP %)   Q = Q<sub>max</sub> × √(ΔP ÷ ΔP<sub>max</sub>)</p>

## Worked example

Range 0–250 mbar = 0–100 m³/h. Measured DP = 62.5 mbar.

- DP % = 62.5 ÷ 250 = 25%
- Flow % = √0.25 = 50%
- Flow = **50 m³/h**

## DP vs flow table

| DP % | Flow % |
|---|---|
| 1% | 10% |
| 4% | 20% |
| 9% | 30% |
| 25% | 50% |
| 49% | 70% |
| 81% | 90% |
| 100% | 100% |

At 10% flow the transmitter sees only 1% of its range, which is why turndown is limited.

## Low-flow cut-off

Because flow is the square root of DP, small DP errors near zero become large flow errors. A 0.1% DP zero error appears as about 3.2% of flow. Most transmitters and DCS blocks apply a **low-flow cut-off**, often 5–10% of flow, below which the reading is forced to zero.

## Rangeability (turndown)

DP flow meters have limited turndown, typically 3:1 to 4:1, because DP falls with the square of flow:

| Flow (% of max) | DP (% of max) |
|---|---|
| 100% | 100% |
| 50% | 25% |
| 25% | 6.25% |
| 10% | 1% |

At 10% flow the transmitter is measuring only 1% of its range. For wider turndown, use two transmitters with different ranges, or a different meter type.

## Where to take the square root

The square root can be done in the transmitter (output linear with flow) or in the DCS (transmitter output linear with DP). Do it in **one place only**. Taking it twice is a common commissioning error.

## Primary elements that use this

- Orifice plates — see the [orifice flow calculator](/engineering/orifice-flow/)
- Venturi tubes and flow nozzles
- Averaging pitot tubes
- Wedge and V-cone meters

## With a 4–20 mA signal

If the transmitter output is linear with DP, mA = 4 + 16 × DP%. For 50% flow (25% DP) that is **8 mA**, not 12 mA. If the transmitter extracts the square root itself, 50% flow reads 12 mA. Use the [4–20 mA calculator](/engineering/4-20ma-scaling/) for the conversion.
