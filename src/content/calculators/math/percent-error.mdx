## How to use the percent error calculator

Enter the **measured** value and the **true** (accepted or reference) value. The absolute difference and percent error appear instantly. You can also work backwards to find the measurement range allowed by a given error.

For more background, read [Accuracy vs Precision](https://www.instrumentationblog.in/difference-between-accuracy-and-precision/).

## Percent error formula

<p class="formula">% error = |measured − true| ÷ |true| × 100</p>

## Worked example

A student measures gravity as 9.6 m/s². The accepted value is 9.81 m/s².

- Difference = 9.6 − 9.81 = −0.21 (the measurement was low)
- Percent error = 0.21 ÷ 9.81 = **2.14%**

## Percent error vs percent change

- **Percent error** compares a measurement with a known correct value.
- **Percent change** compares a new value with an old one — use the [percentage change calculator](/math/percentage-change/).

## Percent error examples

| Measured | True | Percent error |
|---|---|---|

## Absolute, relative and percent error

| Error type | Formula | Units |
|---|---|---|
| Absolute error | measured − true | Same as the measurement |
| Relative error | abs(measured − true) ÷ abs(true) | None (a ratio) |
| Percent error | relative error × 100 | % |

## Sources of error in experiments

- **Random errors**: small unpredictable variations, reduced by repeating and averaging.
- **Systematic errors**: consistent bias, such as an uncalibrated scale or reaction time. Repeating does not remove them.
- **Human errors**: misreading a scale or recording a value wrongly.

Discuss which type is likely when you write up a lab report.

## When the true value is zero

Percent error is undefined when the accepted value is zero, because you would divide by zero. Report the absolute error instead.

## Accuracy specs in instrumentation

Instrument accuracy is often given as a percentage of **reading** or of **span**. A 0–10 bar transmitter with ±0.5% of span accuracy can be off by ±0.05 bar anywhere in its range — which is ±1% at a 5 bar reading and ±5% at 1 bar.
