## How to use this calculator

Fill in any **two** of base, exponent and result:

- **Power:** base and exponent → result (2¹⁰ = 1,024)
- **Root:** exponent and result → base (∛125 = 5)
- **Exponent:** base and result → exponent (3ⁿ = 81 → n = 4)

## Rules of exponents

| Rule | Example |
|---|---|
| xᵃ × xᵇ = xᵃ⁺ᵇ | 2³ × 2⁴ = 2⁷ = 128 |
| xᵃ ÷ xᵇ = xᵃ⁻ᵇ | 5⁶ ÷ 5⁴ = 5² = 25 |
| (xᵃ)ᵇ = xᵃᵇ | (3²)³ = 3⁶ = 729 |
| x⁰ = 1 | 7⁰ = 1 |
| x⁻ⁿ = 1/xⁿ | 10⁻² = 0.01 |
| x^(1/n) = ⁿ√x | 16^(1/2) = 4 |

## Powers of 2

2⁸ = 256, 2¹⁰ = 1,024, 2¹⁶ = 65,536 and 2²⁰ = 1,048,576. These appear constantly in computing — a kilobyte in binary terms is 2¹⁰ bytes.

## Fractional exponents and roots

A fractional exponent is a root:

- x<sup>1/2</sup> = √x, so 16<sup>0.5</sup> = 4
- x<sup>1/3</sup> = ∛x, so 27<sup>1/3</sup> = 3
- x<sup>3/2</sup> = (√x)³, so 4<sup>1.5</sup> = 8

Type 0.5 or 0.3333333 as the exponent to take square or cube roots.

## Scientific notation

Very large and small numbers are written as a × 10<sup>n</sup>, with 1 ≤ a < 10:

- Speed of light ≈ 3 × 10<sup>8</sup> m/s
- Mass of an electron ≈ 9.11 × 10<sup>−31</sup> kg
- World population ≈ 8 × 10<sup>9</sup>

## Common mistakes

- **−2² is −4**, not 4: the exponent applies before the minus sign. Write (−2)² for 4.
- **(a + b)² is not a² + b²**. It is a² + 2ab + b².
- **x<sup>0</sup> = 1** for any non-zero x.

## Growth

Anything that grows by a fixed percentage follows an exponent. Money growing 8% a year for 10 years is multiplied by 1.08¹⁰ = 2.16.
