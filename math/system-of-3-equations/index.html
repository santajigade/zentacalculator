    Three linear equations in three unknowns describe three planes, and when they meet at a single point the system has one solution. This 3 variable system of equations calculator finds that point with Cramer's rule, showing D, Dx, Dy and Dz.

    Students use it to check homework and exam working, and engineers use it for small problems such as mesh currents in a circuit, mixture blends and fitting a parabola through three points.

    How to use the 3 variable system of equations calculator

    Write each equation as a·x + b·y + c·z = d and enter its four numbers. Use 0 for a missing variable. The calculator returns D, Dx, Dy, Dz and the solution; if D = 0 there is no unique solution.

    Cramer’s rule for three equations

    D = a₁(b₂c₃ − c₂b₃) − b₁(a₂c₃ − c₂a₃) + c₁(a₂b₃ − b₂a₃)

    x = Dx/D  ·  y = Dy/D  ·  z = Dz/D

    Dx, Dy and Dz are the same determinant with the x, y or z column replaced by the right-hand sides d.

    Worked example

    Solve x + y + z = 6, 2x − y + 3z = 9 and x + 2y − z = 2:

    • D = 1(1 − 6) − 1(−2 − 3) + 1(4 + 1) = 5
    • Dx = 5, Dy = 10, Dz = 15
    • x = 5/5 = 1, y = 10/5 = 2, z = 15/5 = 3
    • Check: 1 + 2 + 3 = 6 ✓, 2 − 2 + 9 = 9 ✓, 1 + 4 − 3 = 2 ✓

    Solving by elimination

    1. Use equation 1 to eliminate x from equations 2 and 3.
    2. Solve the resulting two equations in y and z (see the two-variable system of equations calculator).
    3. Substitute y and z back into equation 1 to find x.

    The same system by Gaussian elimination

    Elimination reaches the same answer and shows why D matters. Starting from x + y + z = 6, 2x − y + 3z = 9 and x + 2y − z = 2:

    1. Equation 2 − 2 × equation 1 gives −3y + z = −3.
    2. Equation 3 − equation 1 gives y − 2z = −4.
    3. Three times the second new equation plus the first removes y: −5z = −15, so z = 3.
    4. Back substitution: −3y + 3 = −3 gives y = 2, and x = 6 − 2 − 3 = 1.

    Engineering example: three mesh currents

    A resistor network has three loops. Kirchhoff’s voltage law gives, with currents in amps:

    • 15I₁ − 5I₂ = 10
    • −5I₁ + 25I₂ − 10I₃ = 0
    • −10I₂ + 20I₃ = −5

    Enter a₁ = 15, b₁ = −5, c₁ = 0, d₁ = 10 and so on. D = 5,500, giving I₁ = 0.6818 A, I₂ = 0.0455 A and I₃ = -0.2273 A. The negative I₃ means that loop current flows the other way round from the direction assumed.

    What the determinant tells you

    Result Geometry Number of solutions
    D ≠ 0 Three planes meet at one point Exactly one
    D = 0 and all of Dx, Dy, Dz = 0 Planes share a line, or two or three coincide None or infinitely many, check by elimination
    D = 0 and any of Dx, Dy, Dz ≠ 0 Planes do not have a common point None

    For example x + 2y + 3z, 2x + 4y + 6z and x + y + z have D = 0 because the second row is twice the first, so the system cannot have a unique solution whatever the right-hand sides.

    Common mistakes

    • Not lining up the variables. Rewrite each equation as a·x + b·y + c·z = d before entering; 3z + x = 4 means a = 1, b = 0, c = 3.
    • Moving a term without changing its sign. x + y = 6 − z must become x + y + z = 6, with c = +1.
    • Replacing the wrong column. Dy replaces the y column with the right-hand sides, not the y row.
    • Trusting tiny determinants. If D is very small compared with the coefficients, rounding in the inputs causes large changes in x, y and z; the system is ill conditioned.
    • Skipping the check. Substitute the answers back into all three original equations; it catches typing errors at once.

    Frequently asked questions

    How do you solve 3 equations with 3 variables?

    Use elimination to reduce to two equations in two unknowns, or Cramer's rule — x = Dx/D, y = Dy/D, z = Dz/D, where each D is a 3×3 determinant.

    How is a 3×3 determinant calculated?

    By cofactor expansion along the first row, D = a₁(b₂c₃ − c₂b₃) − b₁(a₂c₃ − c₂a₃) + c₁(a₂b₃ − b₂a₃).

    What if the determinant is zero?

    There is no unique solution — the planes are parallel or meet in a line, giving no solutions or infinitely many. Gaussian elimination tells you which.

    Is Cramer's rule efficient?

    For 2×2 and 3×3 systems it is quick and clear. For larger systems Gaussian elimination or matrix methods are far more efficient.

    Can this calculator fit a parabola through three points?

    Yes. For y = ax² + bx + c through (x₁, y₁), (x₂, y₂) and (x₃, y₃), each point gives one equation: x₁²·a + x₁·b + 1·c = y₁. Enter x², x and 1 as the three coefficients and y as the right-hand side, and the solution gives a, b and c.
