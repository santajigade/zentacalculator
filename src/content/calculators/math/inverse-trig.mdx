    a: "arcsin: −90° to 90° (−π/2 to π/2); arccos: 0° to 180° (0 to π); arctan: −90° to 90°, never reaching ±90°; arccot (as used here): 0° to 180°. These principal values make each inverse a true function with one answer."

## How to use the inverse trig calculator

Enter a **value** — a ratio such as opposite ÷ hypotenuse — and read arcsin, arccos, arctan and arccot. Switch any result between degrees, radians, gradians or turns with its unit selector. To go the other way, clear the value and type an angle into one of the result boxes: the calculator returns the sine, cosine or tangent of that angle as the value. arcsin and arccos are only defined for values from −1 to 1.

## Inverse trig formulas and ranges

<p class="formula">θ = arcsin x ⇔ sin θ = x, −90° ≤ θ ≤ 90° &nbsp;·&nbsp; θ = arccos x ⇔ cos θ = x, 0° ≤ θ ≤ 180°</p>

<p class="formula">θ = arctan x ⇔ tan θ = x, −90° &lt; θ &lt; 90° &nbsp;·&nbsp; arccot x = 90° − arctan x</p>

Useful identities: arcsin x + arccos x = 90°, arctan x + arctan(1/x) = 90° for x &gt; 0, and arcsin(−x) = −arcsin x.

## Worked example

Find the angles whose sine, cosine, tangent and cotangent equal 0.5:

- arcsin 0.5 = **30°** (0.5236 rad), since sin 30° = 0.5
- arccos 0.5 = **60°** (1.0472 rad); check: 30° + 60° = 90°
- arctan 0.5 = **26.565°** (0.4636 rad)
- arccot 0.5 = 90° − 26.565° = **63.435°**

In a right triangle with opposite side 1 and adjacent side 2, the angle is arctan(1/2) = 26.57°.

## Practical notes

- **Two-argument arctangent:** arctan(y/x) cannot tell (1, 1) from (−1, −1). For angles of vectors, phasors or coordinates use atan2(y, x), which returns the full −180° to 180° range — see the [vector calculator](/math/vector/).
- **Degrees vs radians:** spreadsheets and programming languages return radians; multiply by 180/π (57.2958) to get degrees. Convert other units with the [angle converter](/math/angle-converter/).
- **Solving triangles:** use arcsin with the [law of sines](/math/law-of-sines/) (watch for the ambiguous case where 180° − θ is also a solution) and arccos with the [law of cosines](/math/law-of-cosines/), which never has that ambiguity.

## Example: the angle of a wheelchair ramp

A ramp that rises 1 unit for every 12 units of run has a ratio of 1 ÷ 12 = 0.0833. Enter that as the value and read arctan: **4.76°**, a gradient of 8.33%. Going the other way, to keep a ramp below 5°, enter 5° in the arctan box: the value returned is 0.0875, so the ramp needs at least 11.4 units of run per unit of rise.

## Angles of right triangles with whole number sides

For a right triangle, arcsin(opposite ÷ hypotenuse), arccos(adjacent ÷ hypotenuse) and arctan(opposite ÷ adjacent) all give the same angle. The other acute angle is 90° minus it:

| Sides (opp, adj, hyp) | sin θ | cos θ | tan θ | θ | 90° − θ |
|---|---|---|---|---|---|
| 3, 4, 5 | 3/5 | 4/5 | 3/4 | 36.87° | 53.13° |
| 5, 12, 13 | 5/13 | 12/13 | 5/12 | 22.62° | 67.38° |
| 8, 15, 17 | 8/17 | 15/17 | 8/15 | 28.07° | 61.93° |
| 7, 24, 25 | 7/25 | 24/25 | 7/24 | 16.26° | 73.74° |
| 20, 21, 29 | 20/29 | 21/29 | 20/21 | 43.60° | 46.40° |
| 1, 1, √2 | 1/√2 | 1/√2 | 1/1 | 45.00° | 45.00° |

The 3, 4, 5 triangle is the one builders use to set out a square corner; its smaller angle is 36.87°, not the 30° or 45° people often assume.

## Common mistakes

- **Calculator in the wrong angle mode.** arcsin 0.5 is 30 in degrees but 0.5236 in radians. Spreadsheets and programming languages always return radians.
- **Asking for arcsin or arccos outside −1 to 1.** No angle has a sine of 1.2, so the result is undefined. A ratio above 1 usually means the opposite and hypotenuse were swapped.
- **Forgetting the second solution.** arcsin 0.5 returns only 30°, but 150° has the same sine. In the law of sines this is the ambiguous case.
- **Using arctan(y/x) for a direction.** The point (−1, −1) gives arctan 1 = 45°, while its real direction is −135° (or 225°). Use atan2(y, x) for vectors and coordinates.
- **Assuming every source defines arccot the same way.** Here arccot x = 90° − arctan x, so arccot(−1) = 135°. Some software uses arctan(1/x) instead, which gives −45° for the same input.
